# Stuffed & Furious

A 16-bit Thanksgiving food-fight brawler for the browser. Two players (USB/Bluetooth gamepads or keyboard) or one player vs CPU (Easy / Normal / Hard).

- 6 fighters, each with a perk and a super move
- 7 foods with different damage, speed, arc, reload and special effects; pack 3 per match
- 3 arenas: Harvest Farm, Grandma's Table, Parade Street
- Original chiptune music, best-of-3 rounds, health bars and a winner screen

Static site, no build step: open `index.html` or deploy the folder to Vercel.
